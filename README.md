# Reference Manager

The website and the downloads for Reference Manager, a local, offline reference manager for Windows and macOS.

- **Website and downloads:** https://thomaschambers15243.github.io/Reference-Manager/
- **What's new:** https://thomaschambers15243.github.io/Reference-Manager/whats-new.html
- **Every version:** the [Releases](https://github.com/ThomasChambers15243/Reference-Manager/releases) page

The app's source code is not published. This repository holds only the website, which is written afresh at each release. Questions and problems are welcome as [issues](https://github.com/ThomasChambers15243/Reference-Manager/issues).
