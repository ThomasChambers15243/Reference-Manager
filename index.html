What’s new →

From your first paper
to the final bibliography.

References, projects and PDFs belong together. Keep them in one place, with the details under your control.

One master library

Store each reference once. Type it in or paste BibTeX, check it in the form, and save; title suggestions and duplicate checks keep the library tidy. People and venues have pages of their own.

Bibliographies for each project

Group references by project and export clean .bib files laid out by your own templates, kept up to date as you work. Citation keys stay put. CSL-JSON, RIS, Typst and 79 citation styles too.

Papers beside their references

Read and annotate PDFs in the app. Drop them in, or let a watched folder bring them; hover a citation to see what it cites, and follow who cites whom in a graph.

Organised the same way everywhere

References, papers, people and venues each have categories and tags. Drag things onto them, and drag one category inside another.

Works packages

A lab’s or a colleague’s project in one file, with its references, notes and, if they choose, the PDFs. It opens as a project, and each reference joins your library only once you have checked it.

Notes, sketches and a timeline

Markdown notes that cite your references, sketch boards for planning, a timeline of what you did when, and a browser tab for finding papers.

Your library stays
on your computer.

Your database, PDFs and annotations are kept together in one folder. Save the whole library as a .zip to back it up or move it to another computer.

By itself, the app only asks this website whether a new version is out, which you can turn off. Web pages load only in the browser tabs you open.

Installing & updating

The installers are not code-signed yet, so your computer asks you to approve them the first time.

Windows

Run the installer on 64-bit Windows 10 or 11. If SmartScreen says “Windows protected your PC”, click More info, then Run anyway.

Mac

Open the .dmg and drag Reference Manager into Applications. It runs on Apple silicon and Intel Macs with macOS 11 or later.

The app is not signed with an Apple developer certificate, so macOS refuses it the first time: try to open it once, then click Open Anyway in System Settings → Privacy & Security. On macOS 14 or earlier, Control-click the app and choose Open.

If macOS says the app “is damaged”, run xattr -dr com.apple.quarantine "/Applications/Reference Manager.app" in Terminal and open it again.

Updating

A few seconds after it starts, the app says when a new version is out, and Update and restart in Settings → Updates installs it. On Windows the app closes, shows a progress bar for a few seconds and opens again; on a Mac the new version takes the old one’s place in Applications and opens. Updating never touches your library, papers or settings.

Versions before 0.7.11 don’t look for new versions on this website. Update one of those by hand once: on Windows, run the new installer; on a Mac, quit the app and drag the new version into Applications, replacing the old one.

Follow the development

Reference Manager is a work in progress. Each release lists what changed, and problems are welcome as issues. To hear of new versions, watch the repository on GitHub (Watch → Custom → Releases).
